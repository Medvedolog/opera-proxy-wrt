# Opera Proxy for OpenWrt — 1.30.0-r4

Пакет **luci-app-opera-proxy** включает прокси-сервер Opera/SurfEasy, веб-интерфейс LuCI, службу procd и настройки UCI. Релиз предназначен для OpenWrt **24.10 (IPK)** и **25.12 (APK)**.

## Изменения относительно v1.30.0-3

- **Меньше лишних сборок:** матрица сокращена до восьми актуальных архитектур: `aarch64_generic`, `aarch64_cortex-a53`, `aarch64_cortex-a72`, `arm_cortex-a7_neon-vfpv4`, `arm_cortex-a9_vfpv3-d16`, `mips_24kc`, `mipsel_24kc` и `x86_64`.
- **Оптимизация размера прошивки:** сохранены параметры компиляции Go `-trimpath -ldflags="-s -w -buildid="`. Для x86_64 и ARM сборка пробует UPX, но использует упакованный бинарник только при успешной проверке целостности и пробном запуске. Для MIPS/MIPSel UPX пока не включён во избежание дополнительной нагрузки на память.
- **Сборка и проверка:** пакеты собираются через owfeed, автоматически устанавливаются в тестовых окружениях OpenWrt 24.10.8 и 25.12.5 и публикуются с подписями и подписанным манифестом.

Сохранены возможности предыдущей версии: автоматические резервные пути к SurfEasy API, переключение конечных серверов, веб-интерфейс с подсказками и сворачиваемыми разделами, диагностика Telegram API, GitHub, Claude, YouTube и ChatGPT.

## Установка по SSH

Сначала узнайте архитектуру и версию OpenWrt:

```sh
. /etc/openwrt_release
echo "$DISTRIB_RELEASE / $DISTRIB_ARCH"
```

**OpenWrt 25.12 — APK** (пример для `aarch64_cortex-a53`; подставьте свою архитектуру):

```sh
ARCH="$(. /etc/openwrt_release; echo "$DISTRIB_ARCH")"
wget -O /tmp/luci-app-opera-proxy.apk "https://github.com/Medvedolog/opera-proxy-wrt/releases/download/v1.30.0-4/luci-app-opera-proxy-1.30.0-r4_${ARCH}.apk"
apk add --allow-untrusted /tmp/luci-app-opera-proxy.apk
```

**OpenWrt 24.10 — IPK** (в том числе для Xiaomi Mi Router 3G, `mipsel_24kc`):

```sh
ARCH="$(. /etc/openwrt_release; echo "$DISTRIB_ARCH")"
wget -O /tmp/luci-app-opera-proxy.ipk "https://github.com/Medvedolog/opera-proxy-wrt/releases/download/v1.30.0-4/luci-app-opera-proxy_1.30.0-r4_${ARCH}.ipk"
opkg update
opkg install /tmp/luci-app-opera-proxy.ipk
```

**Примечание:** локальная установка APK с `--allow-untrusted` обходит проверку доверия к репозиторию. Используйте только пакет из официального раздела Releases; подписи `.sig` и `manifest.txt.sig` опубликованы отдельно. Для последующих автоматических обновлений предпочтительнее подключить подписанный репозиторий пакетов.

После установки откройте **Сервисы → Opera Proxy** в LuCI. По умолчанию локальный прокси слушает `127.0.0.1:18080`; чтобы пользоваться им с другого устройства, нужно отдельно настроить адрес прослушивания и правила доступа.

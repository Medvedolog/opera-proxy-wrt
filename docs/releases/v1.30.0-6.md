# Opera Proxy для OpenWrt — v1.30.0-6 (1.30.0-r6)

> **ТРЕБУЕТ ТЕСТИРОВАНИЯ — предварительный выпуск.** Ревизия предназначена для проверки устойчивости в сетях с «белыми списками», частичной доступностью интернета и на маломощных роутерах. **Не устанавливайте на критически важный маршрутизатор без возможности доступа по SSH.**

## Исправления

- **Защита от перегрузки при блокировках:** по умолчанию не более 2 попыток первоначальной инициализации, резервный поиск API выключен, параллелизм ограничен 2 кандидатами и 10 адресами. Даже если в прежнем UCI остались повышенные значения, init-скрипт ограничит их при запуске.
- **Нет цикла перезапуска:** убран автоматический `procd respawn`, чтобы длительная сетевая недоступность не приводила к постоянному повторному запуску.
- **Редкие попытки обновления:** после сбоя авторизации интервалы повторов нарастают до 15 минут.
- **LuCI не зависит от доступности внешнего API:** при открытии страницы не выполняется поиск стран через исполняемый файл. Журнал загружается по запросу и ограничен 80 строками.
- **Аварийное отключение:** добавлена кнопка **«Отключить автозапуск»**, которая сохраняет `enabled=0`, останавливает службу и отключает запуск при загрузке. Кнопка **«Запустить»** сохраняет `enabled=1`.
- **Установка безопаснее:** новая конфигурация устанавливается с `enabled=0`; скрипт установки учитывает существующий `enabled` и не включает службу вопреки выбору пользователя.
- **Настройки применяются к процессу:** init-скрипт теперь передаёт `api_proxy_builtin`, `api_proxy_parallel`, `api_proxy_max`, `mem_limit_mb`, `idle_timeout`.
- Из предшествующей тестовой ветки r5: диагностика неверных SOCKS-запросов с адресом клиента, уровни syslog, таблица проверки пяти сервисов, русские подписи LuCI.

## Известные ограничения

- **Белые списки не гарантируют доступа к Opera VPN.** Если нужные адреса недоступны, прокси может не запуститься. Это ожидаемое поведение; нагрузка на маршрутизатор должна оставаться ограниченной.
- **Сценарий OPiZ3 + модем с белыми списками ещё не прошёл полевых испытаний.** Сборка, Go-тесты и автоматическая установка в OpenWrt не заменяют такую проверку.
- При обновлении уже установленного пакета сохраняется прежний UCI. Если ранее `enabled=1`, служба останется включённой; при необходимости отключите её до обновления.
- Наличие резервного списка HTTP-прокси не означает, что пользовательский трафик автоматически проходит через эти HTTP-прокси. Они используются при доступе к API/обнаружении адресов.

**Критерий приёмки:** отсутствие непрерывных перезапусков и существенного роста нагрузки CPU на OPiZ3 в режиме белых списков; служба должна останавливаться штатно, а LuCI — оставаться отзывчивым.

## Что проверить

1. **OPiZ3 под белыми списками:** загрузка CPU, память, частота сообщений журнала, скорость открытия сторонних страниц LuCI.
2. **Полное отсутствие интернета:** завершение ограниченных попыток запуска, отсутствие циклов `procd`.
3. **Отключение:** «Остановить», «Отключить автозапуск», запуск и повторная загрузка роутера.
4. **Обычное подключение:** SOCKS5/HTTP, пять диагностических запросов, переключение серверов, повторное обновление авторизации.
5. **Обновление прежней версии:** сохранение UCI и корректное ограничение старых завышенных значений.

При сообщении о неисправности приложите вывод `logread -e opera-proxy | tail -80`, модель устройства, версию OpenWrt, тип подключения и график нагрузки CPU. **Не публикуйте токены, пароли или приватные адреса из конфигурации.**

## Экстренное отключение по SSH

```sh
uci set opera-proxy.main.enabled='0'
uci commit opera-proxy
/etc/init.d/opera-proxy stop
/etc/init.d/opera-proxy disable
```

Если процесс не остановился штатно, только в крайнем случае: `killall -9 opera-proxy`.

## Установка

Сначала уточните релиз и архитектуру:

```sh
. /etc/openwrt_release
echo "$DISTRIB_RELEASE / $DISTRIB_ARCH"
```

**OpenWrt 24.10 (IPK):**

```sh
ARCH="$(. /etc/openwrt_release; echo "$DISTRIB_ARCH")"
wget -O /tmp/opera-proxy.ipk "https://github.com/Medvedolog/opera-proxy-wrt/releases/download/v1.30.0-6/luci-app-opera-proxy_1.30.0-r6_${ARCH}.ipk"
opkg install /tmp/opera-proxy.ipk
```

**OpenWrt 25.12 (APK):**

```sh
ARCH="$(. /etc/openwrt_release; echo "$DISTRIB_ARCH")"
wget -O /tmp/opera-proxy.apk "https://github.com/Medvedolog/opera-proxy-wrt/releases/download/v1.30.0-6/luci-app-opera-proxy-1.30.0-r6_${ARCH}.apk"
apk add --allow-untrusted /tmp/opera-proxy.apk
```

*Для APK флаг `--allow-untrusted` отключает проверку доверия к репозиторию. Предпочитайте подписанный репозиторий owfeed, когда он доступен.*

После установки новая служба **выключена**, включите её в **Сервисы → Opera Proxy** вручную.

Тестовый выпуск: https://github.com/Medvedolog/opera-proxy-wrt/releases/tag/v1.30.0-6

# Opera Proxy для OpenWrt — v1.30.0-7 (1.30.0-r7)

> **ТРЕБУЕТ ТЕСТИРОВАНИЯ — предварительный выпуск.** Не устанавливайте на критически важный роутер без доступа по SSH. Особое внимание — OPiZ3 при белых списках операторской сети.

## Что изменилось относительно r6

- Синхронизированы зависимости с последним коммитом upstream [Alexey71/opera-proxy](https://github.com/Alexey71/opera-proxy/commit/453aa18803760c9c2d3cec9d666845df44a2ec10) от 22 октября 2026 года:
  - Go toolchain: `go1.27.1` → `go1.27.3`.
  - `golang.org/x/net`: `v0.59.0` → `v0.61.0`.
  - `golang.org/x/crypto/x509roots/fallback`: `20260920014000-1f7c531b64a1` → `20261020153306-9f2b28d4331a`.
- Обновлён `go.sum` по проверенным данным upstream.
- **Код сетевого движка и алгоритмы устойчивости из r6 не заменялись**, поскольку у upstream в этом коммите менялись только `go.mod` и `go.sum`.
- Все защитные механизмы r6 сохранены: ограниченные попытки запуска, защита от `procd` restart loop, уменьшенный параллелизм, исправления LuCI и аварийное отключение службы.

## Требует полевых испытаний

1. OPiZ3 с модемом в режиме «белых списков»: загрузка CPU, частота записей `logread`, отклик всех разделов LuCI, штатное отключение.
2. OPiZ3 с нормальной сетью: SOCKS5, HTTP-прокси, выбор серверов, API и периодическое обновление.
3. Проверка на MIPS/MIPSel, AArch64 и x86_64: запуск бинарника, потребление памяти и отсутствие регрессий TLS/DNS.
4. Поведение при полном отключении интернета и повторном восстановлении связи.
5. Установка на существующий r6: UCI должен сохраняться.

## Аварийная остановка

```sh
uci set opera-proxy.main.enabled='0'
uci commit opera-proxy
/etc/init.d/opera-proxy stop
/etc/init.d/opera-proxy disable
```

## Установка

Перед загрузкой проверьте `DISTRIB_ARCH`: `. /etc/openwrt_release; echo "$DISTRIB_ARCH"`.

OpenWrt 24.10 (IPK):
```sh
ARCH="$(. /etc/openwrt_release; echo "$DISTRIB_ARCH")"
wget -O /tmp/opera-proxy.ipk "https://github.com/Medvedolog/opera-proxy-wrt/releases/download/v1.30.0-7/luci-app-opera-proxy_1.30.0-r7_${ARCH}.ipk"
opkg install /tmp/opera-proxy.ipk
```

OpenWrt 25.12 (APK):
```sh
ARCH="$(. /etc/openwrt_release; echo "$DISTRIB_ARCH")"
wget -O /tmp/opera-proxy.apk "https://github.com/Medvedolog/opera-proxy-wrt/releases/download/v1.30.0-7/luci-app-opera-proxy-1.30.0-r7_${ARCH}.apk"
apk add --allow-untrusted /tmp/opera-proxy.apk
```

Флаг `--allow-untrusted` отключает проверку доверия к репозиторию. Используйте подписанный owfeed, когда возможно. На новой установке служба выключена по умолчанию; включайте её вручную после проверки.
